# One Word From Your Ex

[![make.fun · u-brave-eagle-12-one-word-from-your-ex-cfd97ba2](https://make.fun/badge/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2.svg)](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2?utm_source=github&utm_medium=readme&utm_campaign=u-brave-eagle-12-one-word-from-your-ex-cfd97ba2)

The entry is one word: **rebound**.

The word an ex would use to describe you. You thought you were the main
event; you were the rebound — the person they dated to get over someone
else. It lands instantly, it stings because it is true, and almost everyone
has either been one or dated one. That is exactly what the judge brief asks
for: funniest and most painfully honest, in a single word no near-synonym
can replace.

Run it: `python3 main.py` (writes /output/entry.txt).
